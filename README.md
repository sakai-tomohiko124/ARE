# かんたんチャット（GitHub Pages対応）

HTML・CSS・JavaScriptだけで動く、シンプルなチャット風Webアプリです。

## ファイル構成

- `index.html`：画面の構造
- `style.css`：デザインとスマートフォン対応
- `script.js`：送信・表示・ブラウザー保存などの処理

## できること

- 名前を設定する
- メッセージを送信して画面に表示する
- メッセージをブラウザー内に保存する
- 送信日時を表示する
- メッセージ履歴を消去する
- スマートフォンでも使いやすい画面

## 重要：この版の制限

このアプリは**フロントエンドのみのデモ版**です。メッセージは `localStorage` に保存されるため、基本的に同じブラウザー内でのみ表示されます。別の人や別の端末とリアルタイムで会話するためのサーバー機能、ユーザー認証、データベースは含まれていません。

GitHub PagesはHTML/CSS/JavaScriptなどの静的ファイルを公開するホスティングサービスであり、これだけでチャット用のバックエンドサーバーが起動するわけではありません。複数人で使えるチャットにするには、FirebaseやSupabaseなどのバックエンドを追加する必要があります。

## GitHub Pagesで公開する手順

1. GitHubにログインし、新しいリポジトリを作成します。例：`simple-chat`
2. ZIPを解凍します。
3. 解凍したフォルダー内の `index.html`、`style.css`、`script.js`、`README.md` をリポジトリの一番上（ルート）にアップロードします。
4. リポジトリの **Settings** を開きます。
5. 左側の **Pages** を開きます。
6. **Build and deployment** の **Source** を `Deploy from a branch` にします。
7. Branchを `main`、フォルダーを `/(root)` にして保存します。
8. 公開処理が完了すると、Pages画面にサイトURLが表示されます。URLを開いて動作を確認してください。

## ローカルで確認する手順

1. ZIPを解凍します。
2. `index.html` をブラウザーで開きます。
3. 名前を設定し、メッセージを送信してみてください。

※ ローカルファイルとして開く場合、ブラウザーによっては保存機能の扱いが異なることがあります。安定して確認するにはGitHub Pagesに公開するか、ローカル開発サーバーを使ってください。
